## 실행
- 그냥 보기: `index.html` 더블클릭 (AI 버튼만 꺼지고 나머지는 모두 동작)
- AI까지 쓰기:
  1. `.env.example`을 복사해 `.env`로 저장하고 `OPENAI_API_KEY=` 뒤에 키 입력
  2. 이 폴더에서 `python server.py` (설치할 것 없음 · 표준 라이브러리만 사용)
  3. 브라우저로 http://127.0.0.1:8770 열기 → 각 탭 오른쪽 위에 'AI 연결됨'
- 무료 API 키(공공데이터포털 · 한국은행 ECOS · KOSIS · YouTube)도 같은 `.env`에 넣어요. 발급 사이트 · 연결 상태는 대시보드 '데이터 출처 › API 연결'(상단 `API n/8` 칩)에서 60초마다 실시간으로 확인돼요. 저장하면 서버 재시작 없이 1분 안에 반영돼요.
- 키는 서버만 읽고 브라우저로 보내지 않아요. `.env`는 `.gitignore`에 있어 GitHub에 올라가지 않아요.
- AI 원칙(Reboot과 같음): 판단 · 판정은 규칙이 하고, AI는 문장 · 제안만 씀. 근거로 준 값 밖의 소재 · 수치 · 혜택은 쓰지 않도록 지시.

## 데이터 원칙
- 근거 없는 가상 데이터는 쓰지 않음. 판매 · 재고 · 반품 같은 내부 데이터는 '입사 후 연결' 자리로 둠.
- 예외: 성과 분석의 '연습용 가상 데이터'는 화면 시연용이라 실제 브랜드 이름을 쓰지 않고(브랜드 A~F) 빨간 띠로 가상임을 표시.
- W컨셉: robots.txt가 허용한 사용자 요청형 열람으로 화면을 1회씩 읽음 (자동 반복 크롤러 없음, 이미지 저장 안 함).
- 무료 API(키 없음): Open-Meteo(날씨), Nager.Date(공휴일). 페이지를 열면 실시간 호출, 실패하면 `assets/snapshots.js` 값 사용.
- 자세한 출처: `DATA_SOURCES.md`

## 파일
```
index.html
assets/style.css      포트폴리오 프레임 스타일 (검은 프레임 · 흰 캔버스 · 슬랩 세리프)
assets/app.js         화면 · 규칙 · 계산
assets/ax.js          AX 탭 4개 (콘텐츠 제작 · 표현 검수 · 성과 분석 · 시장 인사이트)
server.py             로컬 서버 · OpenAI 호출 대행 (.env 키 사용)
assets/market.js      W컨셉 수집 데이터 (베스트 3회 · 기획전 · 단독 · 신상 · 상품 리뷰)
assets/snapshots.js   무료 API 스냅샷 (실시간 호출 실패 시 사용)
assets/vision.js      MediaPipe 상품 사진 분석
assets/data.js        (이전 버전 가상 데이터 · 사용 안 함 · 지워도 됨)
```
`index.html`을 더블클릭하면 열려요 (인터넷 연결 필요).
