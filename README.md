# Fashion MD Workspace — 패션 온라인MD 대시보드

입점 브랜드를 관리하는 패션 플랫폼 온라인MD의 하루를 한 화면에 모은 대시보드입니다.
W컨셉 [신입사원 공개채용] 온라인MD 공고의 주요업무 4가지를 메뉴로 1:1 구현했습니다.

| 공고 주요업무 | 메뉴 |
|---|---|
| 입점 브랜드 운영/관리 | 입점 브랜드 관리 (등급 · 다음 액션 · 미팅 아젠다 자동 정리) |
| 제품 소싱 및 상품 등록 | 소싱 (수요-공급 갭 · 후보 적합도 · 입점 제안 메일) / 상품 등록 검수 (규칙 12개 + MediaPipe 사진 분석) |
| 기획전, 프로모션 운영/관리 | 기획전 · 프로모션 (목표 페이스 · 할인/쿠폰 수익 시뮬레이터 · 상품 후보) |
| 매출 데이터 관리 및 분석 | 매출 분석 (기간 비교 · 품절 기회손실 · 품절 위험 옵션 · 사이즈 커브) |
| + | 오늘의 브리핑 (규칙 9개 → 이번 주 할 일 + 근거) · 고객 VOC (주제 분류 → 브랜드 요청) |

## 실행
- `index.html`을 더블클릭하면 브라우저에서 열립니다 (인터넷 연결 필요: 폰트 · 차트 · MediaPipe).
- GitHub Pages / Netlify에 폴더째 올리면 링크로 공유할 수 있습니다.

## 파일
```
index.html          화면 틀
assets/style.css    디자인 (블루 사이드바 · 폴더형 퀵 액세스 카드)
assets/data.js      가상 데이터 (브랜드 12 · 상품 · 옵션 · 8주 일별 판매 · 기획전 · VOC · 등록 대기)
assets/app.js       화면 · 계산 · 규칙 (할 일 R1~R9 · 검수 F01~F12 · VOC 주제 분류)
assets/vision.js    MediaPipe Image Classifier + 대표 컬러 · 상품 비중 추출
```

## 원칙 (Reboot 마케팅 대시보드에서 가져옴)
- 판단은 규칙이 하고, 근거를 함께 보여준다. 문장(아젠다 · 메일 · 요청문)은 템플릿으로 만든다.
- PASS는 최종 승인이 아니다. 등록 승인 · 발송은 MD가 직접 확인한다.
- 예시 데이터는 화면에 `예시 데이터` 배지로 표시한다.

## 실제 데이터로 바꾸려면
`assets/data.js`의 `BRANDS · PRODUCTS(options, daily) · PROMOS · VOC · REG_QUEUE`를 같은 모양으로 채우면 모든 화면 · 규칙이 그대로 동작합니다.

모든 브랜드 · 상품 · 수치는 포트폴리오 시연용 가상 데이터이며, 실제 회사 · 브랜드와 관계없습니다.
